# শেখাঘর (Shekhaghor) — সম্পূর্ণ বাংলা অনলাইন শিক্ষামূলক ভিডিও প্ল্যাটফর্ম

> **“শিখুন নিজের গতিতে, এগিয়ে যান আত্মবিশ্বাসে।”**

একটি আধুনিক, সুন্দর, দ্রুতগতির এবং সম্পূর্ণ বাংলাভিত্তিক উন্মুক্ত অনলাইন শিক্ষামূলক ভিডিও ও কোর্স প্ল্যাটফর্ম। এখানে শিক্ষার্থীরা প্রযুক্তি, প্রোগ্রামিং, ফ্রিল্যান্সিং, এআই, গ্রাফিক ডিজাইন ও অন্যান্য বিষয়ের কোর্সসমূহ ধারাবাহিকভাবে শিখতে পারে, অগ্রগতি ট্র্যাক করতে পারে এবং ব্যক্তিগত নোট সংরক্ষণ করতে পারে।

## ১. প্রজেক্টের বৈশিষ্ট্যসমূহ (Features)

- 🎨 **ব্র্যান্ড আইডেন্টিটি ও ডিজাইন:** সবুজ (`#16803C`) এবং হলুদ (`#FACC15`) থিমে সুসংগঠিত বাংলা টাইপোগ্রাফি (Hind Siliguri ফন্ট), বই ও ঘরের প্রতীকসম্বলিত লোগো।
- 📚 **২০টি বাংলা ক্যাটাগরি:** ওয়েব ডেভেলপমেন্ট, প্রোগ্রামিং, গ্রাফিক ডিজাইন, কৃত্রিম বুদ্ধিমত্তা, স্পোকেন ইংলিশ, ফ্রিল্যান্সিং ইত্যাদি।
- 🎥 **৬টি পূর্ণাঙ্গ টেস্টিং কোর্স (MongoDB সিডেড):** প্রতিটি কোর্সে একাধিক অধ্যায় ও পাঠ, আসল কার্যকরী ইউটিউব টিউটোরিয়ালসহ প্রস্তুত।
- 🖥️ **ভিডিও ক্লাসরুম প্লেয়ার:**
  - রেসপনসিভ ইউটিউব এম্বেড প্লেয়ার
  - আগের ও পরের পাঠে যাওয়ার নেভিগেশন
  - অধ্যায় ও পাঠের কারিকুলাম সাইডবার
  - ভিডিও সম্পন্ন হিসেবে চিহ্নিত করার চেকবক্স
  - প্রতিটি পাঠের সাথে ব্যক্তিগত ক্লাসরুম ডায়রি/নোট সেভ করার সুবিধা
  - ভিডিও সংক্রান্ত যেকোনো সমস্যা বা কপিরাইট নোটিশ রিপোর্টের ব্যবস্থা
- 👤 **নিরাপদ ইউজার অথেনটিকেশন ও অগ্রগতি ট্র্যাকিং:**
  - শিক্ষার্থী নিবন্ধন ও লগইন (JWT + Bcrypt)
  - শিক্ষার্থীর ড্যাশবোর্ড (চলমান কোর্স, সমাপ্ত পাঠের হিসাব, বুকমার্ককৃত কোর্স)
  - পাসওয়ার্ড সুরক্ষিত ডেটাবেস স্টোরেজ
- 🛡️ **সুরক্ষিত অ্যাডমিন ড্যাশবোর্ড:**
  - অ্যাডমিন ইউজারনেম: `jasmin`, পাসওয়ার্ড: `jasmin1142005`
  - সাধারণ ব্যবহারকারীদের কাছে অ্যাডমিন লিংক দৃশ্যমান নয়
  - ইউটিউব URL ইনপুট দিয়ে স্বয়ংক্রিয়ভাবে ভিডিওর টাইটেল, থাম্বনেইল যাচাই ও নতুন কোর্স হিসেবে যুক্ত করার সুবিধা
  - কোর্স CRUD (তৈরি, আপডেট, ডিলিট)
  - ক্যাটাগরি তৈরি ও পরিচালনা
  - শিক্ষার্থীদের পাঠানো ভিডিও রিপোর্ট পর্যালোচনা ও সমাধান
  - সিস্টেম অডিট লগ

## ২. প্রযুক্তি ও আর্কিটেকচার (Tech Stack)

- **Frontend:** React 19, TypeScript, Tailwind CSS, Lucide Icons, Google Fonts (Hind Siliguri)
- **Backend:** Node.js, Express.js (REST API)
- **Database:** MongoDB Atlas (Mongoose ODM)
- **Authentication:** JSON Web Tokens (JWT) ও Bcrypt.js
- **Video Integration:** YouTube Embedded Player

## ৪. স্থানীয়ভাবে চালানোর নিয়ম (Local Setup)

১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

২. ডেভেলপমেন্ট সার্ভার চালু করুন (Frontend + Backend একসাথে):
```bash
npm run dev
```

৩. ব্রাউজারে `http://localhost:3000` এ যান। সার্ভার চালু হলে স্বয়ংক্রিয়ভাবে MongoDB ডেটাবেসে অ্যাডমিন ও ৬টি টেস্টিং ক্যাটাগরি কোর্স সিড হয়ে যাবে।
